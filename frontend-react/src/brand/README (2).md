# VITRAS · /brand
Brand asset package · v1.0 · 2026

## Estrutura
- /logos/primary       Lockup horizontal (default)
- /logos/secondary     Lockup vertical (selos / badges)
- /logos/compact       Lockup compacto (topbar / ≤32 px)
- /logos/inverse       Sobre accent / contextos invertidos
- /logos/monochrome    Black / White (impressão monocromática)
- /wordmark            Wordmark isolado (caixa baixa, Plex Sans 500)
- /symbol/svg          Símbolo isolado (Facet) em todas as variantes
- /favicon             favicon.svg + mask + safari-pinned
- /app-icons           iOS / Android / macOS / dark / light / mono
- /social              GitHub / LinkedIn / Twitter / Discord / Slack / OG
- /motion              Specs e referências de motion
- /construction        Folhas de construção geométrica
- /guidelines          Uso correto, don'ts, contraste
- /exports             tokens.json, tokens.css, brand book

## Princípios
- Atemporal > criativo
- Geométrico > orgânico
- Calado > ornamental
- Em dúvida, não use.

## Construção
Grade de 32u. Bloco 24×24 (4→28). Vértice em V por subtração: boca 12u (10→22 no topo), apex em (16,18). Simetria em eixo vertical central. ≤16 px usa `mark-solid` (3→29).

## Tipografia
IBM Plex Sans / IBM Plex Mono — SIL OFL 1.1.

## Cor
Único accent: Signal Cyan #5DD5E8 (#2FA9C2 para print). Dark-mode-first.
Cobertura máxima de accent por tela: 8%.
